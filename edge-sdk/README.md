# 장치 SDK — 언어와 보드 바인딩 미정

백엔드 담당이 작성하고 AI 담당이 실제 보드에 결합하는 저장·통신 코드의 위치다. 현재 SDK 구현은 없다. Spring Boot 애플리케이션을 보드에서 실행한다는 뜻이 아니다.

기본 구성은 AI 판단 모듈과 SDK가 같은 프로세스에서 함수로 연결되는 형태다. AI는 상태 전이·카메라·시계·물리 출력을, SDK는 SQLite의 원자 저장·outbox·통신을 맡는다. 정확한 내부 계약은 `reference/v1.43/개발자료/07_보드내부_SDK_연동계약_v1.4.json`에 있다.

AI 담당이 실제 C7L-EDU의 OS·ABI·런타임·TLS/MQTT 5·SQLite 지원 근거를 제공하면 언어·바인딩을 함께 정한다. 서버 개발은 이 결정을 기다릴 필요가 없다.
