차량의 형태, 업무 용도, 이 구역에서의 허용 여부는 서로 다른 정보다. 공식 YOLOv7 기본 설정에는 car·bus·truck 등이 있지만 택시·학원차량·택배차량이라는 세부 용도는 없다. 추가 분류 없이 기본 모델만으로 이들을 구별한다고 설명하지 않는다.[7]

## 유형별로 관찰할 수 있는 단서와 한계

택시는 지붕 표시나 도색이 단서가 될 수 있지만, 영상만으로 승하차 중인지 손님을 기다리는지 확정하기 어렵다. 학원차량은 승합차·버스 형태와 표지가 단서지만, 노란색이라는 이유만으로 등록된 어린이통학버스라고 확정하지 않는다. 배송차량도 로고·차체가 단서일 뿐 실제 하역 여부나 허용 구간을 증명하지 않는다.

## 자동 용도 분류를 구현하는 방법

탐지된 차량 부분을 잘라 경량 분류기에 입력하고, 연속 영상의 여러 결과가 일치할 때만 용도를 추정해 표시한다. 화면에는 “택시 추정”처럼 불확실성을 남긴다. 기본값은 미상이고, 개발 자료에서 정한 기준보다 점수가 낮거나 결과가 자주 바뀌면 미상으로 유지한다. 모델 점수를 곧바로 실제 확률로 해석하지 않는다.

용도 추정은 안내 기준을 바꾸지 않으며, 관리자가 반복 발생 유형을 확인하는 보조 정보다. 형태 탐지와 용도 필드·관리자 수정 기능은 필수로 구현한다. 택시·학원·배송 자동 분류는 별도 학습·평가가 가능한 유형부터 실험한다. 같은 차량을 여러 프레임으로 촬영한 자료가 학습과 평가에 동시에 들어가지 않도록 차량·촬영 회차 단위로 분리한다. 확보한 실제 차량 수, 유형별 표본 수, 혼동표와 미상 처리 비율을 보고한다. 표본이 부족한 유형의 일반화 성능은 주장하지 않는다.

## 실제로 시간과 용도에 따라 달라지는 운영 사례

원주시는 2026년 5월 무실동 능라동길에 화물 하역 구간 7면을 조성하고, 18~24시에는 학원차량의 30분 이내 주정차를 시범 허용한다고 발표했다.[4] 이 사례는 특정 장소의 운영 발표다. “학원차량은 어디서나 30분 허용”이라는 뜻이 아니며, 현재의 영구 운영 여부나 성과를 의미하지도 않는다.

번호판을 읽지 않는 초기 시스템에서는 특정 등록 차량의 자격을 자동 대조할 수 없다. 예외는 현재 사건을 관리자가 확인해 승인하거나, 구역 전체의 작업 일정으로 적용한다. 차량이 바뀌거나 동일성이 불명확해지면 사건별 예외를 다른 차량에 넘겨 적용하지 않는다.
