## 자동 안내를 시작할 조건

구역과 설정을 등록한 뒤 현장에서 정책을 적용한다. 보정과 영상 품질을 검증하고 구역이 비어 있음을 3초 확인한 다음, 새 확인 사진으로 재개한다. 단순 전원 켜짐이나 서버 접속만으로 방송을 시작하지 않는다. 사진에는 대기·저장 완료·실패·만료 상태를 표시하며 보이지 않는 사진을 있다고 가정하지 않는다.

## 시각 신뢰와 시험 기준

시각 동기화 도구의 추정 오차가 1초 이내인지 확인한다. 최근 외부 동기화 5분 이내는 정상, 같은 부팅에서 유효한 오차 추정이 유지되는 30분 이내는 제한 유지로 본다. 그 외에는 자동 안내를 보류한다. 이는 팀이 선택한 운영 초기값이며 실제 시각 정확도를 보증하지 않는다. 상세 조건과 즉시 중지 예외는 02의 C12를 따른다.

지면 보정은 보정에 사용하지 않은 표식 9개로 RMSE 0.05m 이하·최대 0.10m 이하를 확인한다. 차량 검출 상자의 떨림은 별도 G-AI 시험으로 검증한다. 출력 지연은 외부 60 fps 이상 영상과 오디오로 측정하며, 서로 다른 장치의 UTC를 빼서 500 ms 성능으로 보고하지 않는다. 측정 방법은 03의 마지막 장을 따른다.

QCS610 플랫폼은 확인되었고, 남은 확인은 세부 OS·ABI·SDK 연결·실제 성능·출력 연결, 실험 장소·카메라 선정, 실제 착수일·제출일이다. 정한 통신 규약과 업무 흐름을 다시 선택할 필요는 없으며, 구현 불가가 확인된 항목만 근거와 함께 버전을 올려 수정한다.
