## 5분이 지나야 불법이 되는 것은 아니다

도로교통법상 주차에는 승객을 기다리거나 화물을 싣거나 고장 등으로 계속 멈춰 있는 경우와 운전자가 즉시 운전할 수 없는 상태가 포함된다. 정차는 주차에 해당하지 않는 5분 이하의 정지 상태다. 즉, 5분 미만이어도 주차일 수 있고, 정차가 금지된 장소에서는 짧게 멈추는 것도 문제가 될 수 있다.[1]

대표 금지범위에는 교차로 가장자리·모퉁이에서 5m 이내, 버스정류장 표지 등에서 10m 이내, 소방용수시설 등에서 5m 이내, 지정 어린이보호구역 등이 있다.[1] 표는 2026년 10월 30일 확인한 공식 자료를 요약했다. 제32조는 경찰 지시와 위험방지 일시정지 등의 예외를 두며, 제54조는 사고 발생 시 정차와 필요한 구호 조치를 요구한다.[1][2][3] 이 표는 모든 금지장소·예외를 열거한 단속 기준표가 아니다.

## 이번 시스템이 실제로 판단하는 것

모의 실험의 판단은 “이 구역에서 자동 안내가 켜져 있는가 → 차량이 구역 안에 있는가 → 정상 영상에서 정차를 확인했는가 → 안내 중지나 승인된 예외가 있는가 → 정차시간이 기준에 도달했는가” 순서로 진행한다. 결과는 안내 대상·관찰 중·확인 필요로 표시하고 “불법 확정”으로 표시하지 않는다.

## 구역 규칙이란 무엇인가

구역 규칙은 카메라 화면의 관리 범위, 운영 시간, 첫 안내까지의 시간, 반복 횟수, 작업 중지 일정, 적용 버전을 묶은 설정이다. 실제 도로에서는 표지·고시와 관할기관의 허용 조건을 확인해야 한다. 관리자가 웹에서 설정했다고 실제 도로의 불법행위가 합법으로 바뀌는 것은 아니다.

우리 실험은 하나의 기본 정책을 사용한다. “운영 시간 중 모의 구역에 300초 정차하면 안내한다”를 기본으로 하고, 작업 일정이나 개별 사건의 안내 중지는 별도로 기록한다. 첫 안내 5분은 강남구 고정형 CCTV의 5분 단속간격 사례[21]를 참고한 팀의 실험 정책이다. 법의 정차 정의나 신고 사진 간격이 자동 안내 시점을 정하는 것은 아니다. MOVI의 5분은 효과 집계 기준이다.[13]
