# 원문 머리말

> v1.43에 이관한 v1.42 소개 문장이다. 현재 상태는 [PROJECT_STATUS](../../PROJECT_STATUS.md)를 먼저 확인한다.

Data·AI·백엔드·프론트 각 1명으로 팀을 구성한다. 백엔드가 장치 통신 SDK와 보드 없이 진행하는 연동 개발을 주도한다. 이 문서는 v1.41의 설계와 문장을 유지하면서 C4 아키텍처, 처리 흐름과 현장 개념도를 보완한 v1.42다.

현재 구현, 데이터 수집, 성능 실험은 시작하지 않았으며 임베디드 보드는 대여한 상태다. 이 문서는 검토 의견을 반영한 개발 기준이다. 상세 동작은 02 구현 명세서, 담당과 시험은 03 개발 및 검증 계획서에 정리했다. 본문에 설명한 동작은 구현 요구사항이다. 수치는 선행 자료의 결과, 설계 초기값, 성능 목표로 구분한다.
