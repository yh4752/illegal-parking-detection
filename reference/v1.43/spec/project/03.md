## 보조 기능과 구현 제외 범위

택시·학원·배송 용도 자동 분류는 관리자 참고·통계용 보조 실험이다. 기본 형태 분류와 “용도 미상” 필드, 수동 수정은 유지하되 자동 분류는 별도 데이터가 확보되었을 때 진행한다. 세부 통계의 그래프 표현과 화면 장식은 필수 흐름을 완성한 뒤 구현한다.

번호판 인식·차주 연락·자동 신고·과태료 부과·공공 도로의 법적 위반 확정·사고 원인 자동 판별은 구현 범위에서 제외한다. 다중 차량을 개별 안내하는 기능, 야간·우천·이동 카메라 운용, 모든 카메라 방해 공격의 방어도 초기 성능 주장에 포함하지 않는다.

## 실험으로 답할 기술 질문

① 원본 모델의 차량 탐지 성능을 얼마나 유지하면서 대여 보드에서 실행할 수 있는가. ② 단순 구역 점유 타이머와 비교해 추적·정차·관찰 품질 판단이 오안내를 얼마나 줄이는가. ③ 서버 연결이 끊겨도 현장 안내와 사후 기록 복구가 동작하는가. 각 질문의 비교 조건과 지표는 03 개발 및 검증 계획서에 정한다.

실제 성능은 구현 후 시험으로 평가한다. 현 단계의 목표는 요구사항별로 재현 가능한 시험을 마련하는 것이다. 새로운 알고리즘을 개발했거나 선행 제품보다 성능이 우수하다는 결론은 내리지 않는다.
