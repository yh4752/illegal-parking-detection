## 관리자 종료와 다시 감시할 조건

관리자 확인 기록 자체는 사건을 닫지 않는다. 현재 사건을 지정한 CLOSE_EVENT 명령을 장치가 적용한 뒤 CLOSED_MANUAL로 확정한다. 이때 다시 감시하기 전 확인이 필요하다는 REARM_REQUIRED 보류를 남긴다. 잔류 차량을 새 사건으로 만들어 안내 횟수를 초기화하지 않는다. 빈 구역을 3초 확인하고 새 사진에 근거해 명시적으로 재개해야 다시 사건을 받을 수 있다.

## 규칙 버전과 중지 사유를 따로 관리

장치가 받은 최신 규칙, 장치가 현재 적용한 규칙, 현재 사건이 시작될 때 고정한 규칙의 버전을 구분한다. 시간·횟수 변경은 다음 사건부터 적용한다. 구역 좌표·보정 변경은 즉시 보류하고 기존 사건 정리와 새 구역 확인 후 적용한다. 운영 중 긴급 중지는 설정 버전 차이만으로 거부하지 않는다.

각 중지는 pause_id와 사유·범위를 가진다. 재개는 지정한 중지 기록만 해제하고, 다른 유효 중지가 남으면 계속 보류한다. 공사 종료 시각이 지나도 자동 방송을 재개하지 않는다. 현장 물리 중지는 원격으로 해제할 수 없다. 새 중지 뒤 도착한 오래된 재개가 효력을 갖지 않도록 중지 변경 번호와 확인 토큰을 함께 검사한다.

## 권한과 보관 정책

조회 전용 VIEWER와 제어 가능한 OPERATOR를 구분한다. 장치별 인증·TLS와 토픽 접근 제한을 적용하고, 웹은 HTTPS 세션·CSRF 방어를 사용한다. 브라우저에 장치 계정을 배포하지 않는다. 사진은 7일, 종료 사건·조작 기록은 30일이 기본 보관기간이며 현재 사건과 미확인 전달 기록은 복구에 필요한 동안 먼저 보존한다. 기한 기준·정리 절차·시험은 두 보조 문서에 정한다.

연결이 끊기면 웹은 마지막 상태의 시각과 연결 이상을 표시한다. 마지막으로 비어 있었던 구역을 현재도 비어 있다고 표시하지 않는다. 실제 촬영 전 장소 사용 권한·안내·참여 동의를 확인하며, 운영 카메라의 마이크 녹음은 사용하지 않는다. 별도 성능 시험은 참여 동의하에 외부 영상과 시험음을 기록하고 평가 후 정리한다.
