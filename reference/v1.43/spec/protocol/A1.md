# A1 AI 입력과 정차 판단 규칙

> v1.43 개발 AI 상세 명세 · v1.42 본문 이관 · 구현·실차 시험 전

원문: `02_통신과_상태_구현명세서_v1.42.docx` / A1 AI 입력과 정차 판단 규칙

문서 번호·이전 파일명은 [절별 위치 안내](../README.md)에서 찾는다. 표와 설명의 조건을 함께 적용한다.

이 문서는 구현할 판단 규칙을 정의한다. 실제 성능은 아직 측정하지 않았다. 영상의 탐지 결과와 단조 증가 시각을 입력으로 받아 사건 상태·안내 허용 여부·보류 이유를 출력한다. 좌표와 시간 단위는 지면 m, 경과시간 ms로 통일한다.

| 입력 | 필수 의미와 처리 |
| --- | --- |
| 프레임 | frame_seq, ingest_mono_ms, 처리 시각. 촬영 시각이 제공되면 capture_mono_ms도 기록한다. 역전·반복 순번과 실패한 디코드는 유효 관측에서 제외한다. |
| 차량 관측 | 실제 탐지 상자·차체 종류·검출 점수·관측 여부. 추적기가 예측만 한 위치는 observed=false이며 정차 증거로 쓰지 않는다. |
| 위치와 구역 | 정규화 영상 좌표를 보정해 지면 좌표로 변환한다. 차량 상자의 아래쪽 중앙점을 사용하며, ROI 경계 0.2m 이내는 보류한다. |
| 실행 조건 | 카메라 품질, 사건 동일성, 중지 목록, 출력 상태, 현재 사건에 고정된 규칙 버전을 읽는다. |

YOLOv7 계열의 car·bus·truck 탐지를 시작점으로 한다. 초기 검출 점수 하한은 0.35다. 연속 프레임의 실제 상자를 IoU 최대값으로 연결하고, IoU 0.3 이상인 유일한 대응만 채택한다. 후보가 여러 개이거나 관측 단절 후 연결이 불명확하면 안내를 보류한다. 모델·입력 크기·점수 하한은 vision_profile_id에 기록한다.

## 후보 전체의 이동 범위를 유지

현재 후보에 속하는 최근 실제 좌표 3개의 x·y 중앙값을 각각 계산한다. 최초 3개를 모은 시점부터 후보를 시작하고 그 이전 시간을 더하지 않는다. 이후 평활 좌표의 x·y 최솟값과 최댓값을 누적하고, 이를 감싼 사각형의 대각선 D를 계산한다. D가 0.15m 이내로 3초 유지되면 STOP_CONFIRMED, 같은 후보가 300초에 도달하면 안내 조건을 확인한다. 3초마다 기준점을 바꾸지 않는다.

D가 0.15m를 초과하면 VEHICLE_MOVING을 기록하고 후보를 초기화한다. 관측 실패·가림 의심·경계 진입·운영 중지도 후보를 초기화한다. 사건 ID·안내 시도 횟수·최초 미해소 기준 시각은 유지한다. 후보를 다시 만들 때 이전 후보의 평활 좌표를 섞지 않는다.

입력 대기열은 최신 프레임 1개만 유지한다. 촬영 PTS를 장치 단조 시계에 매핑할 수 있으면 촬영부터 처리까지, 그렇지 않으면 수신 이후 대기시간이 1초를 넘을 때 FRAME_STALE로 보류한다. 수신 시각만으로 카메라 내부의 오래된 영상까지 판별할 수는 없다. 카메라 선정 시험에서 1배속 입력의 실제 지연이 1초 이내인지와 프레임 순서·정지 검출 가능성을 확인한다. 이 조건이 확인되지 않은 입력은 자동 안내 시연에 사용하지 않는다.
