# A4 관측 단절과 부분 가림의 복구

> v1.43 개발 AI 상세 명세 · v1.42 본문 이관 · 구현·실차 시험 전

원문: `02_통신과_상태_구현명세서_v1.42.docx` / A4 관측 단절과 부분 가림의 복구

문서 번호·이전 파일명은 [절별 위치 안내](../README.md)에서 찾는다. 표와 설명의 조건을 함께 적용한다.

정차 증거와 사건 동일성을 분리한다. 검출이 한 번 빠져도 후보 시간은 0으로 돌아가지만, 기존 사건과 안내 횟수는 유지한다. 사건의 차량을 다시 연결할 수 있는지는 아래 조건으로 따로 판단한다. 추적기의 예측 상자만으로 관측 공백을 채우지 않는다.

| 관측 상황 | 동일성 및 복구 처리 |
| --- | --- |
| 실제 검출이 연속 | 매 처리 프레임에서 유일한 상자 대응이 유지되면 같은 사건. 이동으로 후보가 깨져도 정차 후보를 새로 시작할 수 있음. |
| 부분 가림 중 검출 유지 | 가림 단서 때문에 SUSPECT여도 실제 차량 검출·유일 대응이 계속되면 사건 동일성을 유지. 가림 제거 후 정상 5초, 그 뒤 새 후보 300초 필요. |
| 짧은 검출 누락 | 직전 실제 관측부터 새 실제 관측까지 400 ms 이내이며 아래 재대응 조건을 모두 충족할 때만 같은 사건으로 연결. 정차는 초기화하고 정상 5초 뒤 새 후보. |
| 완전 가림 또는 불명확 | 가림 중 대상 검출도 사라짐, 400 ms 초과, 다중 후보, 대응 실패, 장면 교체 의심은 IDENTITY_UNCERTAIN. 자동 새 사건·안내 금지, 관리자 확인. |
| 화면 밖으로 사라짐 | 이탈 관찰 영역에서 3초를 확인하지 못하면 자동 종료하지 않음. 기존 사건을 유지하고 확인 필요 표시. |

## 짧은 누락을 같은 사건에 재대응시키는 조건

새 실제 검출은 점수 0.35 이상이고, 마지막 실제 상자와 IoU 0.5 이상이어야 한다. 구역·경계의 차량 후보는 1대이며 누락 구간에 다른 차량 진입·카메라 품질 이상·가림 단서가 없어야 한다. 처리 시각과 프레임 순서도 정상이어야 한다. 하나라도 맞지 않으면 불명확 보류로 처리한다. 이 규칙은 차량 신원 확인을 대신하지 않으며, 제한된 모의 환경의 연속 관측을 잇는 휴리스틱이다.

400 ms와 IoU 0.5는 개발 설정의 초기값이다. 이 재대응을 허용해도 20초마다 검출 누락이 발생하면 매번 정차 후보가 초기화되므로 첫 안내에 도달할 수 없다. 정상 정차에서 이 문제가 반복되는지는 초기 실행 검증으로 확인한다. 기존 사건 횟수를 지키기 위해 새 추적 ID를 곧바로 새 사건 ID로 바꾸지 않는다.

## 가림 시험의 정답을 사전에 고정

기본 평가의 가림 20건은 일부 가림에도 실제 대상 검출·유일 대응을 계속 관찰할 수 있는 촬영 조건으로 한정한다. 부분 가림의 범위·길이, 가림 제거 후 정상 5초와 정차 300초, 예상 사건 ID를 사전 기록한다. 영상 조건은 사람이 지정하며 모델이 실제 검출을 놓쳐 보류하면 대상 사건의 실패에 포함한다. 결과를 보고 해당 사건을 다른 시험군으로 옮기지 않는다.

완전 가림·가림 중 차량 교체 가능·다중 차량·대응 불명확은 별도 장애 시험이다. 이 경우에는 안내하지 않고 동일성 확인을 기다리는 것이 정답이다. 같은 장면을 안내해야 성공인 대상군과 보류해야 성공인 장애군에 동시에 배치하지 않는다.
