# A3 관찰 품질을 판정하는 최소 알고리즘

> v1.43 개발 AI 상세 명세 · v1.42 본문 이관 · 구현·실차 시험 전

원문: `02_통신과_상태_구현명세서_v1.42.docx` / A3 관찰 품질을 판정하는 최소 알고리즘

문서 번호·이전 파일명은 [절별 위치 안내](../README.md)에서 찾는다. 표와 설명의 조건을 함께 적용한다.

품질 검사는 INTER_AREA로 축소한 320×180 회색조에서 처리한다. 설치 시 정상 영상 5초와 통행영역 밖의 고정 배경 4곳을 관리자가 확인해 기준으로 저장한다. 움직이는 수목·전광판은 제외한다. 아래 값은 vision_profile_id에 묶는 시작값이며 검증된 성능 기준이 아니다. ORB·RANSAC 옵션과 라이브러리 버전도 최초 환경 설정 때 기록해 고정한다.

| 지표 | 초기 계산과 판단 |
| --- | --- |
| 신선도 | 마지막 유효 관측 후 1초 초과는 FRAME_STALE. 새 프레임 도착이 3초 중단되면 NO_FRAME. 순번 역전·디코드 실패는 즉시 보류. |
| 노출 | 전체 픽셀 중 값 5 이하가 85% 이상이면 IMAGE_DARK, 250 이상이 85% 이상이면 IMAGE_BRIGHT. |
| 선명도 | 320×180 회색조, Laplacian ksize=3·CV_64F·BORDER_REFLECT_101, 모집단 분산(ddof=0). 기준의 20% 미만인 패치 3곳 이상은 IMAGE_BLUR. 유효 패치 3곳 미만은 판단 불가. |
| 부분 가림 | 기존 탐지 출력의 다른 person·car·bus·truck 상자가 대상 상자와 겹치는 합집합 면적이 대상 면적의 20% 이상이면 OCCLUSION_SUSPECT. 앞뒤 관계를 확정하지 못하므로 오보류도 평가. |
| 배경 대응 | 차량 상자와 겹치는 패치를 제외하고 ORB 대응점으로 변환 추정. RANSAC 내부점 20개 이상·비율 60% 이상·분포 너비와 높이 각 30% 이상·중앙 재투영 오차 2 px 이하를 요구. |
| 방향 변경 | 신뢰 가능한 변환에서 ROI 꼭짓점 이동량 중앙값이 3 px 초과하면 즉시 보류. 3개 처리 프레임 연속 확인 시 CAMERA_SHIFT와 RECONFIGURE 고정. |
| 판단 불가 | 패치·대응점 부족 또는 신뢰 조건 미충족은 BACKGROUND_UNRELIABLE. 시간이 지났다는 이유로 방향 변경이라고 단정하지 않음. |

어떤 품질 이상이든 확인된 첫 처리 프레임부터 SUSPECT로 출력과 후보를 보류한다. 해당 이상이 2초 연속이면 BLOCKED 알림을 보낸다. NO_FRAME과 RECONFIGURE는 별도 확정 규칙을 우선한다. 픽셀 변화가 작다는 이유만으로 정적 장면을 영상 정지로 판정하지 않는다.

유효 프레임이 돌아오고 모든 품질 조건이 5초 연속 정상일 때 OK로 회복한다. RECONFIGURE는 자동 해제하지 않는다. 정상 영상 회복과 차량 동일성 회복은 별개이며, IDENTITY_UNCERTAIN이 남으면 사건은 HELD다. 이유는 reason_codes 배열에 복수로 기록하고 정상일 때는 빈 배열로 보낸다.

고의 방해나 모든 재생 공격을 알아내는 기능은 아니다. 사람의 통과·조명 변화·저무늬 배경에서 잘못 보류할 수 있다. 기준 패치가 확보되지 않으면 해당 설치를 자동 안내 지원 조건으로 승인하지 않는다. 품질 계산을 포함한 전체 처리속도 5 FPS를 보드에서 확인한다.
