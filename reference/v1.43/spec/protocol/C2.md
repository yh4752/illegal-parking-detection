그림 F07. 브로커 수신 확인과 서버 저장 확인

텍스트 도식: [F07](../../architecture/F07.mmd). 그림별 조건은 [아키텍처 안내](../../architecture/README.md)를 함께 확인한다.

SDK는 상태와 발송 대기를 먼저 저장하고 사건을 보낸다. PUBACK는 브로커의 수신 확인이며, 장치는 서버의 DB 커밋 뒤 보내는 응용 ACK로 전송 완료를 판단한다.

· 응용 ACK 유실 → 같은 message_id·본문·device_seq로 재전송한다. 음성은 재실행하지 않는다.

· DB 저장 실패 → 성공 ACK 없음. 같은 ID·다른 내용 → 격리 후 REJECTED.

· heartbeat는 5초·QoS 0이며 응용 ACK를 요구하지 않는다.

공통 토픽 앞부분은 parking/v2/devices/{device_id}다. 장치 ID는 인증 계정과 대조한다. events·heartbeat·command-results·config/reported는 C1 공통 필드와 전체 snapshot을 포함한다. 새 메시지의 device_seq는 재시작 후에도 증가한다. heartbeat도 새 snapshot을 만들 때 번호를 저장하며, 재전송 메시지의 번호는 바꾸지 않는다.

| 경로와 방향 | 전달 방식 | 공통 필드 외 본문 |
| --- | --- | --- |
| /events 장치→서버 | QoS 1<br>retained 끔 | event_type, event(사건 요약 또는 null), snapshot, image_update |
| /heartbeat 장치→서버 | 5초마다 QoS 0<br>retained 끔 | snapshot, fps, pending_message_count, storage_ok |
| /availability 장치→서버 | QoS 1<br>retained 켬 | device_id, boot_id, connection_id, status ONLINE 또는 OFFLINE |
| /acks 서버→장치 | QoS 1<br>retained 끔 | schema_version, device_id, message_id, status, error_code, committed_at |
| /config/desired 서버→장치 | QoS 1<br>retained 켬 | schema_version, device_id, desired_policy(C3) |
| /config/reported 장치→서버 | QoS 1<br>retained 켬 | config_status, error_code, snapshot |
| /commands 서버→장치 | QoS 1<br>retained 끔 | C4의 명령 객체. MQTT 만료시간 최대 60초 |
| /command-results 장치→서버 | QoS 1<br>retained 끔 | command_id, result, error_code, result_data, snapshot |

events와 command-results는 장치 outbox에 먼저 저장한다. 서버는 원본과 처리 결과를 DB에 반영한 뒤 ACK한다. ACK status는 STORED·DUPLICATE·REJECTED다. 정상 저장과 동일 재전송은 앞의 두 값이고 error_code는 null이다. 같은 message_id에 다른 내용이 오면 MESSAGE_ID_CONFLICT로 격리하며 성공 ACK를 보내지 않는다.

REJECTED는 오류 원본을 서버에 격리 저장했다는 뜻이다. 장치는 일반 재시도를 끝내고 실패함에 보관하며 관리자 확인 상태로 전환한다. 인식 불가능한 envelope에는 상관 가능한 ACK를 만들지 않는다. heartbeat는 저장 확인을 기다리지 않는다. reported는 현재 버전만 재발행하며 과거 reported를 retained로 재전송하지 않는다. 설정 변경 이력은 events로 별도 보존한다.

Last Will은 연결 상태의 보조 정보다. 이전 connection_id의 OFFLINE이 최신 연결을 덮어쓰지 않게 한다. 서버는 새 heartbeat 수신 시각을 기준으로 15초 초과 STALE, 30초 초과 OFFLINE을 표시한다. 과거 사건 기록을 다시 받았다는 이유로 현재 연결 상태를 ONLINE으로 만들지 않는다.
