# A2 사건 상태와 안내 타이머

> v1.43 개발 AI 상세 명세 · v1.42 본문 이관 · 구현·실차 시험 전

원문: `02_통신과_상태_구현명세서_v1.42.docx` / A2 사건 상태와 안내 타이머

문서 번호·이전 파일명은 [절별 위치 안내](../README.md)에서 찾는다. 표와 설명의 조건을 함께 적용한다.

차량 사건, 카메라 품질, 운영 모드, 출력 상태는 독립된 필드다. 안내 허용은 유효한 실제 관측, 동일성 확인, ROI 내부, camera_health=OK, mode=AUTO, 유효한 중지 없음, 출력 정상, 시각 신뢰 유지, 시도 횟수 2회 미만을 모두 요구한다. 재생 직전에도 조건을 다시 검사한다.

| 사건 상태 | 진입 조건과 다음 동작 |
| --- | --- |
| OBSERVING | 아직 안내 시도가 없는 사건에서 새 차량을 관측하거나 후보가 초기화됨. 후보가 3초를 채우면 STOP_CONFIRMED. |
| STOP_CONFIRMED | 아직 안내 시도가 없고 D 기준을 만족하는 후보가 3초 이상. 첫 안내는 후보 300초와 출력 허용 조건을 함께 충족해야 함. |
| GUIDING | 안내 시도와 증가한 횟수를 먼저 로컬 DB에 저장하고 play 요청. 실제 재생·완료 결과는 output_status와 별도 기록. |
| GUIDED | 첫 안내가 완료 또는 중단됨. 첫 재생 종료 후 30초 이상 AND 현재 후보 정차 300초 이상일 때 1회만 추가 안내. |
| HELD | 가림·동일성 불확실·중지·출력 이상 등으로 안내 불가. 사건은 유지하고 이유를 기록. 자동 회복이 가능한 경우만 새 후보 관찰로 돌아감. |
| LONG_UNRESOLVED | 최초 3초 정차 확인 때 고정한 후보 시작으로부터 10분 경과. 관리자 확인 요청. 추가 자동 안내는 하지 않음. 후보 초기화로 기준 시각은 연장하지 않으며, 10분 경계에서는 새 안내보다 미해소 처리가 우선한다. |
| CLOSED_EXIT | 같은 차량의 구역 밖 이동을 3초 연속 실제 관측한 뒤 종료. 미검출 3초는 이탈 증거가 아님. |
| CLOSED_MANUAL | 관리자 확인 종료 명령을 장치가 적용한 경우. 종료 후 재관찰 조건은 통합 명세의 사건 종료 절차를 따름. |

표시 상태는 닫힘 → 보류 → 10분 미해소 → 진행 중 안내 시도(GUIDING) → 종료된 안내 시도 이력(GUIDED) → 3초 정차 후보(STOP_CONFIRMED) → OBSERVING 순으로 결정한다. 시도 선저장부터 완료·중단 결과까지는 진행 중 시도다. 한 번 안내한 사건은 후보를 다시 쌓더라도 GUIDED를 유지하며 후보 시간은 별도 필드로 갱신한다. overdue=true는 별도로 보존하므로 HELD 중에도 10분 경과를 알린다. 10분 도달은 이미 재생 중인 음성을 중단할 사유가 아니며 이후 새 안내만 금지한다.

시도 횟수는 같은 미해소 사건에서 최대 2회다. 추적 번호 변경, 재생 중단, 재시작만으로 되돌리지 않는다. 재안내 간격은 첫 재생의 정상 완료 또는 중단 시각부터 잰다. 출력 실패·불확실은 자동 재안내를 금지하고 현장 확인을 요구한다.

중지 목록과 재개 토큰의 적용은 통합 명세가 기준이다. 재시작·보정 변경·카메라 방향 변경은 중지 상태로 시작하며 mode는 C5의 중지 집합 규칙으로 계산한다. 서버 연결 단절만으로 후보를 초기화하거나 현장 안내를 중지하지 않는다. 로컬 시각·관측·유효 규칙이 유지되는 경우만 현장 동작을 계속한다.

CLOCK_UNTRUSTED는 별도 중지 기록이 아닌 안내 품질 조건이다. 시각 신뢰를 잃으면 새 안내를 금지하고 재생 중 출력은 A5의 stop 절차로 중단하며 정차 후보를 0으로 초기화한다. C12의 시간 신뢰가 5초 연속 회복되어야 새 300초 후보를 쌓고 기존 중지는 유지한다. 최초 안내 시도와 종료 사진은 C11을 따르며 사진 실패로 상태 전이를 막지 않는다.
