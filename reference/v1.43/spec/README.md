# 상세 명세 위치 안내

문서 판본은 v1.43이다. 본문의 설계는 v1.42에서 이관했다. 원문 속 이전 판본·문서 번호는 아래 위치로 연결한다. 소개 문장·그림 캡션에 남은 과거 버전 표기는 새 계약 버전을 뜻하지 않는다.

04·05·07 JSON과 09 구현설계의 원본 파일은 [개발자료](../개발자료/) 아래에 있다. 상대 경로와 내용은 유지했다. 문서에서 `개발자료/...`라고 쓰인 경로는 개발 AI 묶음의 루트를 기준으로 찾는다.

## 현재 읽기 기준

- 형식·필드: 기존 Schema·OpenAPI와 내부 계약 파일.
- 상태·시간·권한·물리 출력·동시성: 해당 상세 절과 의미 검사 목록.
- 구조와 도식: [architecture](../architecture/README.md). 그림만으로 생략된 조건을 추정하지 않는다.
- 규칙이 충돌하면 해당 구현을 임의로 선택하지 않고 위치·영향을 보고한다. 독립된 작업은 계속할 수 있다.
- 기존 원본 경로·검증 명령·고정값을 이관하면서 변경하지 않았다.
