그림 F04. 같은 보드에서 결합하는 AI와 SDK

텍스트 도식: [F04](../../architecture/F04.mmd). 그림별 조건은 [아키텍처 안내](../../architecture/README.md)를 함께 확인한다.

C4 컴포넌트도다. AI는 판단 상태와 실제 출력 제어를 맡고 SDK는 저장·통신을 담당한다. 두 모듈은 내부 함수 호출과 비동기 완료 통지로 연결하며 별도 HTTP 서비스나 IPC를 추가하지 않는다.

· 새 안내와 안전 중단의 실행 순서는 F10을 따른다.

· 카메라 읽기·추론·JPEG 인코딩과 네트워크 작업이 제어 루프를 지연시키지 않아야 한다.

04 JSON은 장치와 서버 사이의 외부 계약이다. 07 JSON은 AI와 SDK 사이의 내부 호출 계약이며 외부 필드나 토픽을 바꾸지 않는다. local_revision은 AI 상태 커밋 때 증가하며 heartbeat·재전송은 바꾸지 않는다. device_seq는 기존 전송 순서 규칙을 따른다.

| 호출 / 제공자 | 입력 → 결과 / 책임 |
| --- | --- |
| restore / 백엔드 | AI가 호출. 저장된 checkpoint·버전·상태·순서를 복원. AI가 재시작 보류와 정차 누적 초기화를 적용. |
| commit_transition / 백엔드 | AI의 operation_id·예상 revision·새 checkpoint·사건/상태/시도/사진 작업 → 원자 저장 결과. |
| 현재 상태 / AI→SDK | AI가 실제 관측 시각·snapshot·fps 제공. SDK가 순서·장치 식별·저장상태·전송대기를 채워 heartbeat 전송. |
| take_command / 백엔드 | 중복·기한을 검사한 명령 전달. AI가 사건·버전·중지·토큰과 현장 조건을 최종 검증하고 실행. |
| 명령 결과 / AI→SDK | 실제 결과·상태 변경을 같은 로컬 트랜잭션으로 저장. SDK가 command-results와 재전송을 담당. |
| 사진 / AI→SDK | AI가 유효 프레임·촬영시각·규격 JPEG 제공. SDK가 용량·작업·해시·재시도·HTTPS 업로드 담당. |
| 시계·출력 포트 / AI | 실물 ClockStatus·play/stop/setLED와 실행 회신 제공. 백엔드는 PC용 모의 구현 제공. |

사건 ID는 AI의 사건 수명에 묶고, message_id·boot_id·device_seq의 생성과 보존은 SDK 경계에서 일관되게 처리한다. AI는 runtime checkpoint의 직렬화 버전을 제공하고 SDK는 해당 상태와 외부 snapshot의 사건·횟수·버전을 함께 검증·저장한다.

백엔드는 원본 영상이나 매 프레임의 탐지 상자를 서버에서 재분석하지 않는다. AI의 추론·판단 구현이 바뀌더라도 외부 통신 계약은 유지하도록 AI 어댑터와 SDK를 연결한다.
