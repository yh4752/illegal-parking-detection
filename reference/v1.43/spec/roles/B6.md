# B6 근거와 남은 실물 확인

> v1.43 개발 AI 상세 명세 · v1.42 본문 이관 · 구현·실차 시험 전

원문: `06_역할분담과_보드없는_개발명세_v1.42.docx` / B6 근거와 남은 실물 확인

문서 번호·이전 파일명은 [절별 위치 안내](../README.md)에서 찾는다. 표와 설명의 조건을 함께 적용한다.

역할 분담은 팀에서 정한 개발 책임을 따른다. 외부 문서는 기술적 구현 방법의 근거로 사용하며 담당자 배분의 근거로 사용하지 않는다. 실제 보드 시험은 아직 수행하지 않았다.

| 근거 | 확인한 사실과 적용 한계 |
| --- | --- |
| 기존 v1.4 | C13~C17, A1~A6, W00~W12를 기준으로 담당·SDK 경계를 개정. 문서 버전 1.4와 네트워크 형식·판단 기준 유지. |
| 세미나 3주차 보고서 | 1쪽 QCS610·Vehicle/Pedestrian/Cyclist, 4쪽 보드 추론 후 PC 후처리. 차종 모델 선정·보드 후처리 통합은 AI 작업. |
| Paho / MQTT 표준 | 장치 클라이언트·발행/구독·TLS 구현 경로. 대여 보드의 현재 OS·ABI 호환은 아직 검증하지 않음. |
| SQLite / GStreamer | 원자 저장과 재생 종료/오류 알림의 근거. 실제 저장장치 내구성과 실제 스피커 출력은 별도 시험. |

남은 실물 확인: 정확한 보드 제품·OS/ABI·런타임/라이브러리, SDK 언어와 바인딩, 카메라·출력 연결, 장소·보정·실측 성능이다. AI가 환경 증거와 실패 로그를 제공하고 백엔드는 공통 소프트웨어 문제를 수정한다.
