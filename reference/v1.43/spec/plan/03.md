## 연속 관측 검증을 판단기 고정 전에 수행

관측 실패 때 후보를 초기화하는 규칙을 유지한다. Data가 정상 정차 360초 개발 영상 10건과 사람이 표시한 정답을 준비하고 AI가 모호한 사례를 교차 확인한다. 실제 관측 가능·정차 시각을 프로그램에 유리하게 옮기지 않는다. Data의 W14 상세 산출물은 06 B5를 따른다.

초기 통과 목표는 관측 가능 시점 후 302초 이내 첫 안내 시도 9건 이상이다. 이는 최종 성능 결과나 보편적 기준이 아니다. 매 20초 관측 누락을 주입한 입력에서는 후보 초기화와 보류를 확인한다. 실패하면 모델·설치·입력 크기·위치 흔들림을 우선 개선한다. 관측 정책 자체를 바꾸려면 이유와 버전을 남기고 서행·가림 반례를 함께 다시 검증한다.

## 파일 영상과 실제 설치의 역할

파일 영상은 실행과 논리 검증을 앞당긴다. 로직 단위시험에는 촬영 시각을 가상 단조시계로 사용할 수 있다. 실제 반응시간은 1배속 재생 또는 실제 장치에서 단조시계와 독립적인 출력 관측으로 측정한다. 빠른 오프라인 재생 시간을 실제 응답시간으로 쓰지 않는다. 카메라 선정 후 입력 지연·보정·연속 정차·출력 중단을 다시 확인하고, 배선은 전압·전류·인터페이스 확인 뒤 진행한다.
