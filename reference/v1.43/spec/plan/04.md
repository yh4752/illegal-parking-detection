## 관리자 기능의 세부 완료 조건

R5-유형수정은 미상 값을 수정하고 다시 조회했을 때 값·수정자·사유·시각이 보존되어야 완료다. 수정은 관리자 참고 정보만 바꾸며 자동 안내 면제를 만들지 않는다. R5-권한은 VIEWER의 조회를 허용하고 제어·설정·유형 수정을 거부하며, OPERATOR의 승인된 작업은 이력을 남기는 것으로 확인한다.

R5-보관은 시험 시각으로 7일·30일 경계를 넘겨 확인한다. 사진은 촬영 후 7일이며 촬영시각을 신뢰하지 못하면 수신시각을 쓴다. 서버 이력은 수신·생성 후 30일, 종료 사건 요약은 종료 후 30일, 명령은 종결 후 30일로 구분한다. 활성 사건·중지·미확인 발송 대기의 운영 최소 상태는 보호하되 오래된 사진과 원본 이력은 예외 없이 지운다. 반복 삭제와 부분 실패 후에도 파일·메타데이터가 일치해야 한다.

## 작업 카드의 필수 항목

모든 작업은 요구 ID·책임 담당·시작 조건·목표 기간·입출력·시험 ID·완료 증거를 가진다. 05 상세 목록의 target_start_day와 target_finish_day는 D 기준 목표다. readiness_gate는 준비 조건이며 날짜가 됐다고 건너뛰지 않는다. 통합은 부분 산출물로 시작하되 완료 표시는 지정 시험을 통과한 뒤에 한다.
