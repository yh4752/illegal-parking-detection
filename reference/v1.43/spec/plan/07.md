# 7 장애와 제어 기능의 인수시험

> v1.43 개발 AI 상세 명세 · v1.42 본문 이관 · 구현·실차 시험 전

원문: `03_개발과_검증계획서_v1.42.docx` / 7 장애와 제어 기능의 인수시험

문서 번호·이전 파일명은 [절별 위치 안내](../README.md)에서 찾는다. 표와 설명의 조건을 함께 적용한다.

아래 시험은 기본 120건과 별도로 수행한다. 정해진 반복에서 통과했음을 의미하며 모든 실제 장애가 해결됐다는 뜻은 아니다. 동일 입력을 반복할 수 있는 통신·명령 시험은 가상 장치로 먼저 하고, 출력·가림·설치에 의존하는 시험은 실제 장치에서 확인한다.

| 시험 ID | 상황과 반복 | 기대 결과 |
| --- | --- | --- |
| TC05·06 | 가림·입력 중단·방향 변경<br>동일성 유형별 5회 | 출력 보류와 이유 표시<br>불확실한 이탈·동일성 자동 확정 없음 |

자동 사건 사진은 최초 안내 시도·종료 때 1개씩이며 제어 확인 토큰을 만들지 않는다. 사진 오류는 안내·종료를 막지 않는다. TC23은 번호판 가림·관리구역 2대·배경 차량·관리자 사고/공사 중지를 포함한다. 사고는 실제 충돌로 재현하지 않는다.

## 시험 결과를 남기는 형식

시험 ID, 입력 자료·명령, 모델·정책·스키마 버전, 초기 상태, 기대 결과, 실제 결과, 시작·끝 시각, 로그·영상 위치, 통과·실패·미수행, 재시험 사유를 한 행으로 기록한다. 장애 후 자동 안내가 없다는 결과만 보고하지 말고 복구·재개가 가능한지도 함께 확인한다.
