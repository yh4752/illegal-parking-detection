## 보드 연결과 AI 성능 완성을 구별

D+14는 보드에서 메시지를 발행하고 명령에 답하는 통합 목표다. 카메라·비전·실제 출력의 성능 완료를 뜻하지 않는다. 보드 통신에 시험 사건을 넣었다면 화면과 로그에 시험 입력임을 표시하고 실제 감지 결과와 섞지 않는다.

## 실물 준비가 늦어질 때

보드·카메라가 늦으면 서버·웹은 가상 장치로 계속 검증한다. G-AI가 실패하면 실제 판단기를 고정하지 않고 원인과 재시험 목표일을 기록한다. 장소·출력 준비나 안전한 중단 수단이 없으면 실차 자동 안내를 진행하지 않는다. 실패를 통과로 바꾸지 않으며 이후 실물 의존 일정만 조정한다.

W10의 후보 조사·허가와 W12의 모델 변환·최적화 준비는 앞 단계와 병행한다. 최종 설치 승인은 W02·W09 후, 최종 성능 비교는 W10 후에 한다. 구매 전 품목별 실제 견적·대여 여부·전원·고정 비용을 기록하고 팀이 정한 예산 안에서 선택한다.
