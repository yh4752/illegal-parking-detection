문서 번호·이전 파일명은 [절별 위치 안내](../README.md)에서 찾는다. 표와 설명의 조건을 함께 적용한다.

Data가 수집·라벨·분할 목록과 정답을 관리하고 시험 결과를 취합한다. AI는 실제 모델·보드 실행, 백엔드는 통신·복구 실행, 프론트는 표시 검증을 담당한다. 평가자가 모델 출력을 정답으로 대체하지 않는다.

1건은 차량 한 대의 진입·정차·이동·이탈 상황이다. 여러 프레임이나 같은 영상을 잘라 만든 조각을 독립 차량 수로 세지 않는다. 개발 자료에서 모델·임계값을 조정하고, 최종 자료는 차량 또는 촬영 회차 단위로 분리한다. 같은 원본의 인접 프레임이 개발과 평가 양쪽에 들어가지 않게 한다.

## 부분 가림과 동일성 불명확 상황의 구분

기본 부분 가림 20건은 타깃의 실제 검출과 유일한 대응이 모든 처리 프레임에 남는 조건으로 지정한다. 별도 누락 시험에서는 실제 검출 간격 0.4초 이하·상자 IoU 0.5 이상·후보 1대·품질 정상·가림 단서 없음일 때만 같은 사건에 재대응한다. 후보 시간은 초기화하고 정상 5초 뒤 새 300초를 확인한다. 하나라도 불충족하거나 완전 가림이면 동일성 확인 보류다. 이 제한적 대응은 차량 신원이나 교체 불가의 보증이 아니다.

## 정답과 제외 규칙

사람이 원본 영상에서 차량 상자, 구역 안팎, 실제 정차·이동·이탈 시각, 가림 범위, 안내 허용 시각을 라벨링한다. 모호한 사례는 두 담당이 검토하고 시험 전 분류를 확정한다. 프로그램 출력은 정답으로 쓰지 않는다. 최종 결과를 확인한 뒤 어려운 사례를 분모에서 제거하지 않는다.

기본 분모는 대상 60건·비대상 60건이다. 대상의 미안내·계속 보류는 실패이며, 비대상의 불필요한 보류·관리자 개입은 별도 집계한다. 사건을 첫 안내 직후 잘라내지 않고 예정된 이탈·가림까지 평가한다. 차량이 한 대뿐이면 그 차량과 지정 조건의 반복 검증으로 보고하고 다른 차종·현장 성능으로 일반화하지 않는다. 대상은 300초 정차가 확보되도록 촬영하고, 가림·이동은 회복 후 300초가 미해소600초 전에 끝나도록 사전 배치한다. 긴 장애는 별도 보류 시험으로 분리하며 실패 후 분모를 바꾸지 않는다. 대상60건의 정차만 최소5시간이며 촬영은 여러 회차로 나눈다. 배속은 실제5분 시험을 대신하지 않는다.
