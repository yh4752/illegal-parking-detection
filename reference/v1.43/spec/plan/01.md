## 첫 공동 산출물은 같은 사건을 설명하는 예제

02 통신과 상태 구현명세서의 정상 사건, 중복·순서 역전, 중지·재개 예제를 공통 입력으로 사용한다. 각 담당이 별도의 상태명이나 가상 사건을 만들지 않는다. 첫 연결은 가상 장치 → 서버 저장 → 웹 표시와 중지 요청 → 장치 적용 회신까지로 한정한다. 촬영 장비가 없어도 통신과 화면 해석을 먼저 검증할 수 있다.

## 진행과 완료를 혼동하지 않는 기록

작업 상태는 미착수·진행·검증 대기·완료로 기록한다. 구현 파일이 있다는 이유만으로 완료하지 않고, 지정된 시험과 입력 버전·기대값·실제값·로그 위치를 남긴다. 기능이 실패하면 담당과 재시험 항목을 정한다. 목표를 변경할 때는 변경 이유와 정책·모델 버전을 함께 남긴다.

Data는 자료·라벨·평가를, AI는 모델·보드·판단·출력을 맡는다. 백엔드는 통신 계약·장치 SDK·가상 장치·서버·배포·통합을 주도한다. 프론트는 관리자 화면을 구현한다. 실제 보드 설치·드라이버는 AI 책임이다. SDK와 AI의 내부 경계는 06과 07을 따른다.
