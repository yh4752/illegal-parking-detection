# 9 설치 보정·시간 지연·중앙 비교의 시험 방법

> v1.43 개발 AI 상세 명세 · v1.42 본문 이관 · 구현·실차 시험 전

원문: `03_개발과_검증계획서_v1.42.docx` / 9 설치 보정·시간 지연·중앙 비교의 시험 방법

문서 번호·이전 파일명은 [절별 위치 안내](../README.md)에서 찾는다. 표와 설명의 조건을 함께 적용한다.

아래는 앞으로 수행할 실험 설계다. 숫자는 팀이 선택한 초기 기준이며 공인 기준이나 측정 결과가 아니다. 조건을 충족하지 못하면 범위를 줄이거나 재시험하고 실패를 기록한다.

| 시험 | 방법과 통과 기준 |
| --- | --- |
| 바닥 좌표 보정 | 보정에 쓰지 않은 표식 9개를 근·중·원거리 감시/이탈 영역에 분산한다. 줄자 실측과 변환 좌표의 거리 오차를 계산한다. RMSE 0.05m 이하·최대 0.10m 이하. 실패하면 시야·범위·보정을 수정한다. |
| 카메라 입력 지연 | 외부 60 FPS 이상 영상에 실제 점멸과 보드 수신 미리보기를 함께 촬영한다. 표시 지연을 포함한 보수적 상한 1초 이하를 확인한다. 프레임 역순·입력 정지는 별도 시험한다. |
| 이동과 출력 중단 | 차량·상태 표식·경고 LED와 스피커 소리를 한 외부 영상에 기록한다. 실제 이동은 사람이 라벨링하고 단조시계 로그와 대조한다. 0.2m/s 이상 이동→MOVE 1.5초 이하, MOVE/중지 수락→실제 음성·LED 중단 500 ms 이하. |
| 측정 불확실성 | 시작·끝 반복 표식으로 프레임 간격·표식 지연·로그 대응 오차를 확인한다. 불확실성 50 ms 이하이며 측정값+불확실성≤목표일 때 통과다. 대응 오차 불명이면 전체 이동→중단만 보고하고 세부 500 ms 기준의 통과 여부는 판단하지 않는다. |
| 중앙과 엣지 | 같은 6분 영상, 1배속, 조건별 3회. 동일 모델·가중치·크기·후처리로 보드 분석과 동일 원본 스트림의 PC 분석을 비교한다. 결과 지연·FPS·누락·양방향 전송량, 양쪽 사양·가속기·코덱·망을 기록한다. |

바닥 보정은 좌표변환 오차만 검사한다. 차량 상자 하단점과 바닥 접점의 차이·검출 떨림은 G-AI 정상 정차 10건으로 별도 확인한다. 출력 중단은 무음 없는 시험음을 같은 드라이버로 재생해 먼저 재고, 실제 안내 음성도 확인한다.

호스트 UTC의 단순 차감으로 지연을 채점하지 않는다. 중앙 비교는 공통 입력 표식과 결과 표시를 외부 영상으로 확인하거나 측정 가능한 공통 관측점을 쓰고 그 지연을 기록한다. 동일 조건이 불가능하면 대체 조건과 제한을 밝힌다.
