# Data 담당 작업 안내

담당 범위는 영상 출처·사용권·수집·정제·라벨·정답·자료 분할·평가 기록이다. 서버 메시지 발행이나 모델의 실제 판단 코드를 Data가 소유하지 않는다. [역할 기준 B1](../spec/roles/B1.md)

## 먼저 진행할 작업

W14에서 개발 자료 인계 기준을 정하고 자료 목록·라벨 지침·분할 계획을 만든다. 개발용 정상 정차 360초 영상 10건과 정답의 인계 목표는 D+7이다. 영상이 아직 없다면 확보 경로·권리·촬영 조건과 미확보 상태를 기록한다. 실제로 확보한 것처럼 만들지 않는다.

먼저 읽을 자료: [현장·데이터 작업](../spec/plan/03.md), [수집과 기본 120건 평가](../spec/plan/05.md), [인계 기준 B5](../spec/roles/B5.md), [작업·시험 원본](../개발자료/05_개발작업과_시험목록_v1.4.json)의 W14.

## 입력과 전달물

| 받는 것 | 만드는 것 | 전달 대상 |
|---|---|---|
| 클래스·정차·이동·가림 요구, 수집 가능한 자료 | 출처·권리 목록, 영상·라벨·정답, 차량/회차 단위 분할 목록 | AI 담당 |
| 모호한 라벨에 대한 AI 검토 | 교차 검토 기록과 고정한 라벨 지침 | 전원 |
| 장소·촬영 가능 조건 | 후보·허가·촬영·자료 분리 계획 | AI·백엔드·프론트 |
| 각 구성 요소의 실제 시험 로그 | 사건별 정답·결과 비교표, 분모·실패·미수행 기록 | 전원·최종 보고 |

## 이후 작업

1. W14: 개발 자료와 최종 평가 자료를 분리한다. 모델 출력을 정답으로 사용하지 않는다.
2. W10: 현장 후보와 허가 준비를 병행한다. 실제 장치 설치·보정·출력 인수는 AI가 맡으며, 실차 시작은 기존 승인 조건을 만족한 뒤 진행한다.
3. W11: 고정된 기본 120건과 별도 장애 시험을 기록한다. 60 대상·60 비대상 분모와 실패·보류·미수행을 보존한다.
4. W12 협업: AI의 성능·경량화·중앙/엣지 비교에 사용한 자료·분모·재현 조건을 점검한다.

상세 시나리오와 채점은 [평가 기준](../spec/plan/06.md), [인수시험](../spec/plan/07.md), [설치·비교 시험](../spec/plan/09.md)를 참조한다. 계획을 만들었다는 이유로 실험을 통과했다고 기록하지 않는다.

## 완료 확인

- TC03에 사용할 개발 자료의 정답과 AI 결과를 대조할 수 있다.
- TC21의 장소·촬영 조건과 자료 분리를 확인하고 실제 설치 결과는 AI에게 받는다.
- TC22·TC23의 전체 분모·실패·보류·미수행이 남는다. TC24 비교의 데이터·조건 고정을 지원한다.
- 개발/평가 자료 중복 방지, 출처·권리, 라벨 지침과 버전을 함께 전달한다. 세부 통과 기준은 [작업·시험 원본](../개발자료/05_개발작업과_시험목록_v1.4.json)을 따른다.

## 팀원에게 넘길 결과

자료 위치와 버전, 확보 수량·미확보 항목, 출처·사용 조건, 라벨 지침, 분할 기준, 모호한 사례, 정답 대조 방법, 다음 담당이 실행할 절차를 적는다. 촬영·평가를 수행하지 않았다면 계획과 실제 결과를 분리한다.
