# 현재 구현 범위

2026-11-15 · 공통 기준 `main` · 제품 기준 v1.43

**실제 API에 연결된 React 인계판을 구현했습니다. 공개 HTTPS 배포와 받는 분의 PC 인수는 아직 완료하지 않았습니다.** 코드·문서는 공개 [저장소의 main](https://github.com/yh4752/parking-system/tree/main)을 공통 기준으로 사용합니다. MQTT → 조회 기반 → 인증·조회 → React 인계의 기존 누적 이력은 PR #4 → #1 → #2 → #3으로 통합합니다. 새 작업은 main에서 브랜치를 만들고 main 대상 PR로 올립니다. 프론트 시안의 적용 범위와 v1.43 차이는 [적용 기준](frontend-design-alignment.md)에 정리했습니다. 시안의 디자인 변경 자체는 아직 구현하지 않았습니다.

## 검사 기록

로컬 자동 검사: 백엔드 일반 **144개**, PostgreSQL **75개**, 프론트 **24개**, 가상 장치 **3개**, 계약 보호 **6개**. 빌드·타입 검사도 수행했습니다. 버전·커밋·CI별 성공 여부와 수정 이력은 [검증 JSON](../validation/frontend-handoff-2026-11-14.json)을 기준으로 합니다.

별도 Linux CI에서 처음 설치부터 Docker 기동·실제 브라우저 로그인·MQTT 저장·SSE·모바일·재접속을 검사합니다. 뒤늦은 낮은 순번 원문도 현재 구역 revision을 바꾸지 않고 상세 화면에 자동 반영되는지 확인합니다. DB 단절 중 성공 ACK 금지, 브로커 단절 시 outbox 보존과 복귀, 서버 재시작 후 이력 보존·이전 세션 무효화도 실제 서비스로 시험합니다.

사용자가 기존에 실행한 `parking-local`의 DB·컨테이너는 초기화하지 않았습니다. 인계 환경은 `parking-handoff`, 포트 18080/18081, 별도 DB/볼륨/쿠키를 사용합니다. CI 통과는 상대방 PC에서의 실제 인수나 외부 HTTPS 접속 성공을 대신하지 않습니다.

## 다음에 필요한 것

| 남은 작업 | 선행 조건 |
|---|---|
| 담당자 저장소 접근·개인 PC 실행 확인 | 열람·클론은 공개. 직접 push는 협업자 권한, 인계 설명서 8번 체크 |
| 공개 HTTPS 배포 | 사용할 Linux 서버·접근 권한·예산, 도메인/DNS |
| 운영 구성·관찰·복원 검증 | TLS/ACL·DB 권한 분리·운영 지표, 백업과 독립 revision manifest 위치, 격리 복원 시험 |
| 실물 보드 연결 | 보드 런타임·SDK 결합 확인, AI 담당자와 계약 검증 |
| 관리 명령·정책 변경·사진 파일 | 별도 제품 기능 구현·인수 시험 |

현재 Compose는 로컬 인계용입니다. 외부로 포트만 열어 공개 운영판으로 사용하지 않습니다. 대규모 느린 TCP 부하·호스트 유실 복원·실제 AI/차량/물리 출력 성능은 검증하지 않았습니다.
