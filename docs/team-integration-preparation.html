실제 연결 확인 순서

  1. 기존 계약의 가상 사건 1건을 고정한 뒤 보드 담당자의 출력과 매핑한다.
  2. 승인된 외부 작업 단계에서 서버·주소·인증서·장치 계정을 설정한다.
  3. 다른 네트워크에서 TLS 이름 검증·잘못된 인증 거부·다른 장치 토픽 거부를 확인한다.
  4. 사건 발행 → DB 행 확인 → 응용 ACK → 웹 조회/SSE 반영을 동일 message_id/event_id로 대조한다.
  5. 연결 단절·재접속·중복 전송·오래된 순번을 시험하고 잘못된 상태 덮어쓰기가 없는지 확인한다.
  6. 백업 중 실제 접속 상태, 재개 후 pending 해소, 외부 사본 복원 결과를 확인한다.
