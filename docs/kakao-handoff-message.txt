캡스톤 개발 코드와 실행 안내 공유드립니다.

현재 백엔드와 기본 프론트 화면을 연결해 로그인, 구역 현황, 사건 목록·상세, 실시간 갱신까지 구현해 두었습니다. 실제 보드 연결 전이라 가상 장치가 보내는 데이터로 동작합니다.

실행 방법과 인계 자료는 아래에서 확인하실 수 있습니다.
https://github.com/yh4752/parking-system/blob/feat/frontend-handoff/docs/team-handoff.md

개발을 시작하실 때는 아래 명령으로 저장소를 클론해 주세요.

git clone --branch feat/frontend-handoff https://github.com/yh4752/parking-system.git

현재 작업 기준은 feat/frontend-handoff 브랜치입니다. main에는 아직 이번 구현이 반영되지 않았습니다. 클론한 parking-system 폴더에서 개인 작업 브랜치를 만들어 개발하고, PR의 기준 브랜치는 feat/frontend-handoff로 지정해 주세요.

프론트 담당자께서는 우선 본인 PC에서 로그인 → 구역 현황 → 사건 상세까지 실행해 보시고, 이후 디자인·배치·모바일 화면을 개선해 주시면 됩니다. 코딩 AI를 활용하실 때는 클론한 저장소의 docs/frontend-handoff-context.json을 먼저 읽도록 요청해 주세요. API·인증·실시간 통신 규칙을 변경해야 한다면 함께 맞추겠습니다.

협업자로 초대하려고 하니 각자 GitHub 아이디 또는 프로필 링크도 보내주세요. 초대 전에도 클론과 로컬 작업은 가능하며, 초대를 수락하면 본인 브랜치를 저장소에 push할 수 있습니다.

현재는 각자 PC에서 실행하는 개발 환경이며, 외부에서 접속할 웹 주소는 아직 없습니다.
