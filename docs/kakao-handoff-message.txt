캡스톤 코드랑 실행 방법 정리해서 공유드려요!

백엔드와 기본 프론트 화면을 연결해서 로그인, 구역 현황, 사건 목록·상세, 실시간 갱신까지 구현해 뒀어요. 아직 실제 보드를 연결하기 전이라 가상 장치가 보내는 데이터로 동작해요.

실행 방법과 개발할 때 참고할 자료는 아래에 모아뒀어요.
https://github.com/yh4752/parking-system/blob/feat/frontend-handoff/docs/team-handoff.md

아래 명령으로 저장소를 클론해서 시작해 주세요.

git clone --branch feat/frontend-handoff https://github.com/yh4752/parking-system.git

현재 코드는 feat/frontend-handoff 브랜치에 있고, main에는 아직 합치지 않았어요. 클론한 parking-system 폴더에서 각자 작업 브랜치를 만들어 개발해 주세요. PR도 feat/frontend-handoff를 기준으로 올려주시면 돼요.

프론트 쪽은 우선 본인 PC에서 로그인 → 구역 현황 → 사건 상세까지 실행해 보시고, 디자인·배치·모바일 화면부터 다듬어 주시면 될 것 같아요. API나 인증·실시간 통신 쪽을 바꿔야 하면 같이 맞춰봐요.

코딩 AI를 쓰실 때는 저장소 안의 docs/frontend-handoff-context.json을 먼저 읽어달라고 하시면 돼요. 필요한 문서와 작업 범위를 정리해 뒀어요.

그리고 협업자로 초대할 수 있게 각자 GitHub 아이디나 프로필 링크도 보내주세요! 초대 전에도 클론해서 작업할 수 있고, 초대를 수락하면 본인 브랜치를 push할 수 있어요.

지금은 각자 PC에서 실행하는 방식이고, 외부에서 접속할 웹 주소는 아직 없어요. 실행하다 막히는 부분 있으면 오류 메시지랑 같이 알려주세요.
