프론트 개발을 이어갈 수 있도록 코드와 인계 자료를 공유드립니다. 로그인, 구역 현황, 사건 목록·상세, 실시간 갱신까지 백엔드와 연결해 두었습니다. 현재 데이터는 가상 장치가 보낸 값입니다.

함께 개발할 코드이므로 ZIP 다운로드 대신 아래 명령으로 클론해 주세요.

git clone --branch feat/frontend-handoff https://github.com/yh4752/parking-system.git

현재 개발 코드는 main이 아닌 feat/frontend-handoff 브랜치입니다. 클론한 parking-system 폴더에서 각자 작업 브랜치를 만들어 개발해 주세요. PR의 기준 브랜치는 feat/frontend-handoff로 지정하면 됩니다.

전달 자료와 실행 방법은 아래에 모았습니다.
https://github.com/yh4752/parking-system/blob/feat/frontend-handoff/docs/team-handoff.md

우선 본인 PC에서 로그인 → 구역 현황 → 사건 상세까지 실행되는지 확인 부탁드립니다. 이후 디자인·배치·모바일 화면과 사용성을 개선해 주시면 됩니다. AI를 활용하실 경우 클론한 저장소와 docs/frontend-handoff-context.json을 함께 읽게 해 주세요.

협업자로 초대하려고 하니 각자 GitHub 아이디 또는 프로필 링크도 보내주세요. 공개 저장소이므로 초대 전에도 클론·로컬 작업은 가능하고, 초대를 수락하면 본인 브랜치를 저장소에 push할 수 있습니다. API·인증·실시간 통신 규칙 변경은 함께 맞추면 됩니다.

현재는 각자 PC에서 실행하는 인계판이며, 웹 서비스의 외부 접속 주소는 아직 없습니다.
