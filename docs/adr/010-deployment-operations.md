# ADR-010: 첫 공개 배포와 복구 경계

2026-11-16 · 설계 채택, 구현·외부 배포 전

기존 ADR-005/008의 단일 서버·조회 인계판을 유지한다. Linux x86_64 + Compose + Nginx, 백엔드 1개로 공개한다. 최초에는 가상 장치만 연결하고 MQTT 외부 포트를 열지 않는다. 운영 내부 MQTT에도 TLS/계정/ACL을 적용한다. 관리 지표는 내부 수집과 SSH 터널로 확인한다.

배포·복원은 별도 작업이며 main 병합이 자동 배포를 뜻하지 않는다. 운영 프로필·권한·모니터링·격리 복원 시험이 완료되기 전에 기존 로컬 Compose를 외부로 열지 않는다.

기존 로컬 revision 파일 두 개만으로 동시 과거 복원·호스트 유실을 검출할 수 없다. 예약 범위와 초기화 claim을 사용하기 전에 버전 보존/CAS가 가능한 독립 저장소에 확정하는 방식을 추가 설계한다. 저장소·권한·실제 지원 API를 확인하고 장애 시험해야 한다. 이 변경은 아직 구현되지 않았다. 독립 기록의 최신성을 증명하지 못하면 자동 복구하지 않는다.

운영 부담은 단일 서버 장애 시 중단과 수동 배포·인수다. 고가용성·무손실 복구·실보드 성능을 보장하지 않는다. 코드 저장소 공개·v1.43 제품 원본·MQTT DTO는 변경하지 않는다.
