# ADR-011: 불법주정차 감지·안내 목적을 드러내는 이름

2026-11-17 · 사용자 선택: `illegal-parking-detection`

## 배경과 결정

기존 `parking-system`은 일반적인 주차장 관리 시스템으로 읽힐 수 있고, ‘엣지 AI 주정차 안내 시스템’이라는 제목에는 불법주정차 감지 목적이 드러나지 않았다. 발표용 주소의 `demo`도 제품 목적보다 시험 환경을 앞세운다.

표시 제목은 **엣지 AI 기반 불법주정차 감지·안내 시스템**, GitHub 저장소 이름은 **illegal-parking-detection**으로 정한다. 짧은 `parking-watch`보다 목적을 직접 설명하는 이름을 선택했다. 기존 저장소의 이름을 변경하며 저장소를 새로 만들거나 Git 이력을 다시 쓰지 않는다.

README는 목적 → 현재 구현 상태 → 실제 실행 화면 → 로컬 실행 → 개발·학습 자료 순서로 읽는다. AI가 판단하고 서버가 결과를 저장·전달한다는 역할을 설명하며, 가상 장치 기반 검증과 실물 AI 감지·안내의 미완료 범위를 같은 화면에서 확인할 수 있게 한다. 이름 변경은 제품 기능이나 감지 성능 검증의 추가를 뜻하지 않는다.

## 변경 범위와 보존 경계

- 현재 개발·인계 문서의 GitHub URL, 클론 명령, 새 클론의 기본 폴더 이름, AI용 인계 JSON을 갱신한다. HTML·SVG는 원본에서 다시 생성한다.
- GitHub 소개 문구도 불법주정차 감지·현장 안내·관리자 관제 목적에 맞춘다.
- 기존 클론은 원격 주소만 갱신한다. 로컬 폴더는 그대로 사용해도 된다. [팀원용 절차](../../CONTRIBUTING.md#저장소-이름-변경-후-기존-클론-연결하기)를 따른다.
- Compose 프로젝트·볼륨, DB·애플리케이션 내부 식별자, 통신 계약은 유지한다. 표시 이름을 바꾸기 위해 기존 데이터와 연결된 이름까지 바꾸지 않는다.
- `reference/v1.43` 원본과 `validation/`의 과거 로그·캡처·JSON·해시는 수정하지 않는다. 당시 저장소 이름과 경로는 기록의 일부다. 현재 문서의 링크 목적지만 새 주소로 맞춘다.
- 실제 서비스 주소는 별도 결정이다. 저장소 이름의 선택으로 DNS 등록·구매·외부 배포를 진행하지 않는다.

## 링크와 검증

GitHub는 이름 변경 후 기존 웹·Git 주소를 새 주소로 연결한다. 다만 이전 이름으로 새 저장소를 만들면 그 연결이 끊길 수 있으므로 `parking-system`을 다른 저장소 이름으로 재사용하지 않는다. [GitHub 공식 이름 변경 안내](https://docs.github.com/en/repositories/creating-and-managing-repositories/renaming-a-repository)

문서 재생성·링크 검사·v1.43 원본 검사, 변경 전후 저장소 ID 비교, PR #5·이슈 #6 접근, 기존 주소의 연결을 확인한다. PR과 main의 CI가 실제 실행 결과이며, 이 결정문 자체는 검사 통과를 대신하지 않는다.
