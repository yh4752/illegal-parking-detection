# ADR-009: 코드 저장소 공개와 팀 전달

2026-11-14 · 사용자 요청에 따라 적용

`yh4752/parking-system`을 private에서 public으로 변경했다. GitHub 메타데이터의 `visibility=public`, 인증 없는 API/인계 문서의 HTTP 200 응답을 확인했다. 원격 브랜치를 갱신하고 Git 이력의 blob 646개를 대상으로 주요 인증키 패턴과 민감 파일명을 검사했으며 해당 후보를 발견하지 않았다. 이 검사는 모든 형태의 비밀정보 부재를 보증하는 전수 보안 심사는 아니다.

누구나 코드·설계를 열람하고 클론할 수 있다. 원본 저장소 직접 push 권한은 별도 협업자 초대가 필요하다. 저장소 공개와 운영 웹 배포는 구분한다. 로컬 Compose의 DB·MQTT 포트나 웹 서비스를 외부에 공개하지 않았다.

팀 전달 기준은 `feat/frontend-handoff` 브랜치와 [팀 전달 안내](../team-handoff.md)다. 기본 브랜치 변경·main 병합·협업자 초대·카카오톡 발송은 이번 변경에 포함하지 않는다. ADR-002/005의 비공개 유지 결정은 이 요청으로 대체하며 v1.43 보존 원본은 변경하지 않는다.

## 2026-11-15 협업 기준 갱신

사용자 요청으로 기존 누적 PR을 main에 통합하고 팀 공통 기준·클론·PR 대상을 `main`으로 통일한다. 위의 인계 브랜치 지정은 당시 전달 상태이며 현재 절차는 [협업 안내](../../CONTRIBUTING.md)를 따른다. 과거 브랜치와 검증 기록은 보존한다. 제품 v1.43 원본·통신 계약·웹 공개 배포 범위는 바꾸지 않는다.

## 2026-11-17 저장소 이름 갱신

현재 이름은 `yh4752/illegal-parking-detection`이다. 이전 공개 전환 기록의 `parking-system`은 당시 이름이며, 변경 이유와 자료 보존 범위는 [ADR-011](011-project-identity.md)을 따른다.
