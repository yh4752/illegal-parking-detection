## 전달 가능 여부의 의미

**코드 인계 가능:** H01~H03, H06과 새 체크아웃 자동 검사가 통과한 상태. 담당자가 실제 API에 연결된 UI를 받아 수정할 수 있습니다. 공개 주소가 없으면 ‘로컬 실행 인계판’이라고 명시합니다.

**공개 인계 완료:** 위 조건에 H04·H05와 외부 PC 인수까지 추가로 통과한 상태. 아직 이 상태로 표시하지 않습니다.

공개 서버·접근 권한·비용 범위, 도메인/DNS, 프론트 담당자의 GitHub 계정, 백업/독립 manifest 보관 위치가 확인되어야 운영 배포와 상대방 인수를 끝낼 수 있습니다. 해당 정보가 없어도 로컬 실행·UI 개선은 시작할 수 있습니다.
