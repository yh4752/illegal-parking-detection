# 4GB 사전 검증과 팀 통합 배포 준비

Goal: 기존 자료를 보존한 격리 환경에서 30분간 5명의 HTTPS 조회와 가상 장치, 백업 중 자원·응답을 측정한다.
Architecture: 공유 Docker VM은 변경하지 않고 시험 전용 Compose 오버레이에 서비스별 메모리/스왑 상한을 둔다. OS/Docker 여유를 별도로 남긴 예산 모델이며 실제 4GB VM·Lightsail amd64/2vCPU 성능 인수가 아니다. 현행 O4 백업은 중단형이며 중단을 실패 통계에서 숨기지 않는다.

- [x] 기존 컨테이너 ID·볼륨·실행 상태 보존, 이 프로젝트 학습 스택만 중지.
- [x] 제한 오버레이와 측정 도구 작성. 새 프로젝트/볼륨·키·루프백 포트만 사용.
- [x] 정상 10분, 백업 포함 10분, 회복 10분. HTTPS 사용자 5명 각 초당 최대 1회 조회, 가상 장치 반복 생성 및 ACK 확인. 메모리·CPU·OOM·재시작·응답 표본을 보존.
- [x] DB 행 수/전송 결과, 백업 검증 및 서비스 복구 확인. 시험 환경만 중지하고 기존 스택 재시작.
- [x] 결과·한계·조기 배포 예산 5만원·실제 배포의 차단 항목과 보드 연결 기준 정리.
- [x] 문서/계약 검사. 계정 생성·구매·외부 배포·원격 push는 수행하지 않음.
