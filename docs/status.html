검사 기록

로컬 자동 검사: 백엔드 일반 144개, PostgreSQL 75개, 프론트 24개, 가상 장치 3개, 계약 보호 6개. 빌드·타입 검사도 수행했습니다. 버전·커밋·CI별 성공 여부와 수정 이력은 검증 JSON을 기준으로 합니다.

별도 Linux CI에서 처음 설치부터 Docker 기동·실제 브라우저 로그인·MQTT 저장·SSE·모바일·재접속을 검사합니다. 뒤늦은 낮은 순번 원문도 현재 구역 revision을 바꾸지 않고 상세 화면에 자동 반영되는지 확인합니다. DB 단절 중 성공 ACK 금지, 브로커 단절 시 outbox 보존과 복귀, 서버 재시작 후 이력 보존·이전 세션 무효화도 실제 서비스로 시험합니다.

사용자가 기존에 실행한 parking-local의 DB·컨테이너는 초기화하지 않았습니다. 인계 환경은 parking-handoff, 포트 18080/18081, 별도 DB/볼륨/쿠키를 사용합니다. CI 통과는 상대방 PC에서의 실제 인수나 외부 HTTPS 접속 성공을 대신하지 않습니다.
