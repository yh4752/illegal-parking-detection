보존은 현재 로컬 Git 작업 트리 기준이다. 원격 push나 독립 외부 사본 회수 검증을 완료했다는 뜻이 아니다. 실제 암호화 백업·키·계정 값은 비공개 `.local-state`에 남기고 공개 근거에는 넣지 않았다.
